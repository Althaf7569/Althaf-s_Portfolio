## 📌 About

Portfolio-ATLAS is a modern, responsive portfolio website built to showcase my professional journey, technical skills, and business accomplishments.

Rather than a traditional portfolio, this project focuses on demonstrating measurable impact through data-driven solutions, workflow automation, and business intelligence.

## ✨ Features

- Modern responsive design
- Smooth scrolling navigation
- Animated statistics counters
- Typing text animation
- Interactive user interface
- Business-focused project showcase
- Timeline-based experience section
- Downloadable resume
- Contact section with social links
- Mobile-friendly layout
